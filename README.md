# 📚 AI Study Assistant

An AI-powered study assistant built using Python, Streamlit, and Google Gemini.

It helps students understand topics, ask questions, summarize notes, generate quizzes, create study plans, and ask questions from uploaded PDF study material.

## 🚀 Live Demo

👉 [Open AI Study Assistant](https://ai-study-assistant-ck2xdjooxkk52mn4bro7sm.streamlit.app/)

## ✨ Features

- 💬 Ask AI study questions
- 📚 Explain difficult topics in simple language
- 📝 Summarize study notes
- 🎯 Generate MCQ quizzes
- 📅 Create personalized study plans
- 📄 Upload PDF study material
- 🔍 Ask questions from uploaded PDFs
- 🤖 AI-powered answers using Google Gemini

## 🛠️ Technologies Used

- 🐍 Python
- 🎨 Streamlit
- 🤖 Google Gemini API
- 📄 PyPDF
- 🐙 GitHub
